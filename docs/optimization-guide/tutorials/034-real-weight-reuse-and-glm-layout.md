## E037：同一份 FP4 权重服务多行输入

普通逐行验证会对每个 token 发起一次投影。相邻调用是否命中 cache 取决于实际执行，
不能仅凭调用顺序认定读带宽已节省。新的 107 行候选明确把复用放进 Metal kernel：
每次载入并解码一个权重后，更新 T2/4/8 份独立累加器。

保留每行原有的乘加顺序、scale 应用位置、SIMD 归约和 BF16 舍入，禁用 contraction，
因此没有为了命中吞吐更高的原生多行矩阵路线而改变基准答案。
这是默认 OFF 的局部投影模块，尚未安装进生产引擎。

源码及运行器先提交并推送 `2dd1e44`，随后真实 GPU smoke 以 0 退出：

- **36/36 用例通过**，候选、原生 MLX 独立 M1、现有 custom B1 的全部 BF16 输出逐字节相同。
- T2/4/8；小矩阵覆盖普通值、正零、负零、较大有限值，并分别使用连续/隔列 stride2 输入。
- 另外覆盖 K5120/N256、K5120/N6144，两种布局均测试；每个 oracle 确实独立调用 M1。
- 保存原始输入、量化前小块、packed 权重、三路输出及源文件 SHA。观测到的 MLX peak 为
  71,516,160 字节；这不是进程 RSS 或整模型内存上限。

[E037 原始证据与独立审计](../../experiments/m5-ultra-256gb/E037-nvfp4-multirow-device-v1/README.md)
保留全部用例。测试运行时原 oMLX 服务已经恢复，因此本轮只作数值验证。
没有 kernel 性能、完整模型状态、接受/拒绝、回滚或 HTTP 加速结论。

事后独立核验通过：108 个 BF16 输出矩阵，三组对照共 559,104 个原始 word 比较，
全部有限且相同；全部输入配方与保存的量化前 BF16 值也逐字节核对。
首次离线审计因“stderr 必须为空”的错误假设退出 1：实际 stderr 只有一条
`mx.metal.device_info` 弃用提示。保留失败源码、日志和结果，仅接受这条精确提示后，
第二次离线审计以 0 退出。没有重跑 GPU、修改输出或放宽数值标准。

下一道检查是实际模型投影的量化和缩放合同。最小接入面可以从 verifier 尾部投影开始，
但只有覆盖各层的大头权重才有机会带来大幅收益；尾部检查通过不代表骨干网络已经复用。
每一步都要计入连续化、拼接、保留状态及失败草稿的成本。

[实际 head 接入审查](../../../bench/reviews/2026-10-19-multirow-head-integration.md)
确认 K5120/N248320、untied NVFP4、无额外外部缩放，满足候选形状条件。
head 权重与 scale 共 715,161,600 字节，占完整投影权重/scale 逻辑扫描的 **4.9621%**。
这不是实测 DRAM 或耗时比例；剩余约 95% 位于 decoder 投影，才是更大的复用机会。
实际 head 比 smoke 最大的 N6144 更大，仍必须做完整词表和全部 prefix state 数值检查。

## E036：把 GLM expert 堆叠从运行时移到磁盘布局

E034 在加载阶段触发既定 swap 增长门槛，未发出任何请求。
一个可检验的方向是减少加载时大量零散 expert 张量的堆叠与临时生命周期。
离线 repacker 保留原始 packed 值、量化参数和所有字节，只改变容器布局。

计划先提交 `096a7af`，随后实际运行 **502.31 秒，以 0 退出**：

| 项目 | 实际结果 |
|---|---:|
| 原始张量 | 113,446 |
| 重排后张量 | 4,960 |
| 形成的 backbone expert stacks | 378 |
| 输出 safetensors 分片 | 58 |
| 不变的 payload 总字节 | 203,976,457,080（约 190 GiB） |

运行程序在复制前重新校验所有原始分片完整 SHA，复制时记录分组 SHA，随后独立回读
输出并核对。没有数值转换；原 checkpoint 保留。MTP 层仍保留原字节及官方加载路径。
所有大 payload 文件描述符在 I/O 前启用 Darwin F_NOCACHE，不能将其解释为零内存或零 swap 保证。

[E036 完整 metadata 证据与独立审计](../../experiments/m5-ultra-256gb/E036-glm-expert-repack-v1/README.md)
区分运行时完整 payload 校验和事后的 header/index/manifest 独立核验。
约 190 GiB 权重留在本机，Git 中保存可复核清单，不重复打包模型。
独立 metadata 核验及归档回读已通过，164 个显式成员完整保留。

这项结果是 **PASS_BYTES_ONLY**。尚未实际通过官方 loader、整模型输出或性能资格；
下一次加载仍沿用原资源门槛，不因为离线复制成功而放宽。是否降低峰值内存必须由实际
加载实验回答，文件个数和张量个数下降都不是峰值内存测量。
