## 本章尝试替换什么

```text
原来：卷积 → SiLU → 拆头/复制QK → 状态更新kernel
候选：卷积 → 新kernel（内部完成SiLU、按头取QK、更新状态）
```

少生成几个中间数组，可能减少提交和搬运；新kernel也可能重复算SiLU。原实验保留BF16中间舍入，并分别做局部、完整模型与HTTP检查。其完整模型数值检查通过，但HTTP吞吐改善约0.632%，未达到当时预先规定的1%采用门槛，因此保持独立实验。该门槛是本次实验的决策条件，不是所有优化的通用标准。
