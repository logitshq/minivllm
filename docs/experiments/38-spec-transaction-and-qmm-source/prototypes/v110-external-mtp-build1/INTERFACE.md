Runtime API (import tutorial_code.miniengine.spec.external_mtp):
- ExternalMTPAdapter() starts enabled=False/draft=None. prepare(target, draft_dir, enabled=False) performs no draft load/allocation. Only strict enabled=True loads239MB draft, binds, and resets. This adapter is a plain Python owner, never assigned as an nn.Module child of target.
- try_draft(anchor_int, target_hidden[1,1,5120], block_size=3, batch_size=1, greedy=True, features=False, mode='decode') returns proposals [1,block_size-1] INT32. OFF, unprepared, B>1, nongreedy, feature, and prefill modes returnNone so the caller retains its original path. There is no service request routing yet.
- draft.reset(target) validates original target embedding/head bindings and original parameter owners, clears independent own-KV/seed/pending round. These borrowed modules use object.__setattr__; they are not registered among23 draft parameter arrays or among1349 target arrays. No packed weight or embedding/head copy is made.
- draft.prefill_from_target_hidden(prompt[1,T], normalized_hidden[1,T,5120], first_bonus_int) pairs shifted prompt+bonus with actual target prompt hidden, builds own KV, and produces the first pending draft seed. Alternatively reset then set_shared_kv({}, target_offset) supports an empty drafter KV at nonzero absolute position, with no target KV borrowed.
- draft.set_shared_kv({}, target_offset) records metadata only; own KV valid length and absolute RoPE frontier are separate. MTPAttention overrides only the RoPE offset source; own projection/QK norms/SDPA/gated output are reused.
- draft.accept_verified_tokens(committed_hidden[1,accepted+1,5120], exact_outstanding_proposal_object, accepted_int, delivered_list) trims speculative KV, replays missing accepted inputs plus next bonus using the **authoritative committed target hidden only**, and seeds the next round. delivered_count and hidden rows must both equal accepted+1. Reset is required before abandoning a pending round. Scalar checks precede trim; no future saved target token is consulted.
