# V29–V32 原始实验快照

这些源码是实验记录，没有替换仓库的主运行时代码。V29/V31/V32 的性能实验均未通过采用条件；V30 只做了数值检查，没有性能结果。

`prototypes/` 和 `root-owners/` 按实际文件原字节复制；`source-map.json` 保存原路径、大小和 SHA。`evidence.tar.gz` 保存原始文本 PASS/STOP、控制组、资源、进程回收及外部不存在证明，全部成员的 SHA 位于 `evidence-index.json`。未包含模型、原始输入/输出张量、原生 binary；原收据里保存这些本地文件的 SHA。

脚本依赖原实验目录中的旧接口、模型和保存的输入；这些绝对路径需要适配。这份快照不构成独立可重跑安装包，也不把旧收据当作新采集。Metal 片段所依据的 MLX MIT 许可随相应原型保存。
