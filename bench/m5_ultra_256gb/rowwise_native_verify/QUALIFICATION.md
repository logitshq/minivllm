# Rowwise forward-prefix qualification with optional multirow head reuse

The head-reuse implementation is source-sealed and its 40 focused CPU mechanism
tests passed on 2026-10-19. This task has performed no device execution. The empty
CLI only describes the contract. The actual CPU-validated plan and command arrays
are in `head-prereg-v1/`; see its README. An existing cold/resource owner must
launch the standard three arguments, retain the exact plan and own hard reap:

```text
python -I -B qualify.py --plan PLAN --plan-sha256 SHA --out NEW_DIRECTORY
```

The exact seven-field plan is `schema: Rowwise-native-verifier-plan-v2`,
`qualifier_sha256`, `candidate: {path, sha256}`, `bridge: {path, sha256}`,
`head_projection: {path, sha256}`, `e024_plan: {path, sha256}`, and `deadline_s` (positive, at most 1800 seconds).
Candidate/bridge/kernel paths and digests must match their sealed sources. The
unchanged inherited E024/E023 plan supplies model, tokenizer, source, environment
and normal-EOS identity. It supplies **no E024 compiled qualification** here.

There are nine cases: T2/4/8 at first decode `max_len=257/1023/1024`. `max_len`
includes the current token: its absolute write position is `max_len-1`, and
`lens=max_len`. All subsequent positions, lengths and bounds increment by one.
Every KV backing has exactly 1536 slots, including all unused padding.

The shortest original D8 fixture (ties by ID) is selected. At used257, its exact
first256 IDs form a **new diagnostic prompt**, not the original full prompt's
semantics. At used1023/1024 the original full prompt is preserved and the native
C1 oracle generates the necessary continuation. Exact original/derived prompt
IDs, source fixture, greedy IDs and seed positions are retained. The old bridge
`acquire_seed` is not reused: it requires position >256 and would allocate only
768 slots for the short prompt. This entry explicitly admits position256 and
passes 1536 to the unchanged batch allocator. EOS or cap512 before coverage is
INCOMPLETE; no ignore-EOS, fabricated IDs, resampling or retries.

Direct reuse is limited to the bridge's source/contract validator, reference
token causality and complete-state representation; the frozen E023 Comparator
and isolation raw dump implement the original finite/original-dtype bit gate.
One fresh native model uses original B1 `runner.decode_model` at every teacher
step. These positions are above its original compiled256 route. Gates remain
ON and norm reuse OFF. No E024, GDN-prework or parameter replacement is installed.
The candidate receives only a fixed block already generated by that reference.

The optional `head_project` seam changes only the final vocabulary projection.
It preserves every original M1 norm, concatenates those normalized rows, then
passes the actual live untied head U32 weights/U8 scales to the pinned multirow
kernel. It does not batch a layer or norm, pack/replace parameters, or change
prefix states. Default OFF does not inspect the projector; omitted `head_project`
retains the previous M1 projection. The explicit qualifier arm requires one
successful evaluated head call per block and never silently falls back. It tests
actual K5120/N248320, not the synthetic smoke's largest N6144. Invalid T1/B2/bounds
must not invoke the head callback. Each case retains its exact shape/dtype/call
receipt; the independent auditor requires all nine and still checks every saved
full-vocabulary logit and all prefix states. Dispatch identity is a source-bound
producer receipt, whereas numerical equality is recomputed from raw bytes.

Each seed's eight reference prefix outputs are written once and reused by the
three widths. Each candidate call independently loads the same canonical state.
After **all** candidate outputs/states are actually evaluated, the original
supplied input arrays and metadata are dumped and compared against the saved
before state. Every compared prefix writes its full vocabulary row plus all128
states before comparison. All42 candidate prefixes must pass; argmax is only an
additional cross-check. KV wrappers/handles must be distinct across prefixes.
T1, B2 and an out-of-bound window must reject without changing supplied state.

Both model/source manifests are rechecked, including tokenizer files. Every
original-dtype parameter value is hashed before and after; handle IDs are only
recorded. These are producer parameter receipts, not an independent offline
rehash of model payloads. Full raw states can require tens of GiB if all cases
pass; external admission must budget disk and the retained T8 states. This is
not a memory-peak or performance test. Any early failure keeps its raw prefix,
first differing tensors where the Comparator reaches them, and FAIL/INCOMPLETE
terminal evidence. An independent raw audit is still required before any use.

Only `forward_prefix_qualified` can become true. Compiled blocks, accepted-prefix
publication, rollback, EOS retirement, scheduler/ahead, HTTP and performance
remain unqualified. The old E027 native multirow failure remains unchanged;
this entry compares original B1 calls in a different traversal order.

CPU head-reuse attempts are retained in this directory. `cpu-head-reuse-v1` failed
before running tests because its import guard rejected the standard-library
socket import used by unittest.mock/asyncio. `cpu-head-reuse-v2` passed 40/40,
with no skips, unchanged sources, no MLX/numpy/torch imports, and process/network
operations forbidden. It covers 13 candidate, 13 qualifier and 14 auditor
methods. Fake arrays prove mechanism only, not native arithmetic, MLX storage
ownership, compiler behavior or device performance. The original CPU snapshots
remain in earlier experiment artifacts; this change does not promote them.
